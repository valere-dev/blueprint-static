## 2. The 28 template formats (PLAYBOOK §7)

| format | treatment | proven by |
|---|---|---|
| Rangée / progression d'objets (bananes qui grandissent, silhouettes qui rétrécissent) | inverser ou garder la progression pour montrer MOINS de centimètres à la taille ; les silhouettes regardent vers le résultat | S1, S8, S16, S38, S44 |
| Même personne en deux portraits (avant/après, 'after X vs after X with brand') | cadrer taille-haut pour que le ventre soit l'avant/après | S2, S52, S76, S83, #6 |
| Un corps coupé en deux (moitié gonflée / moitié tonique) | un seul homme, même peau, nombril exactement sur la coupe | #77 |
| Timeline mois / semaine / jour en photos | profils ou ventres qui rétrécissent, vers la droite ; garder leur timeline seulement s'ils en ont une | S38, S40, S53, S69, #13, #16 |
| Thermique / rayons X / coupe anatomique | le ventre (ou le torse) s'illumine ; les labels = ses symptômes ; pas de produit si le template n'en a pas | S6, S22, S79, #2, #23 |
| Checklist de symptômes / '8 signs of…' | '8 SIGNS OF HIGH ESTROGEN IN MEN' avec des symptômes qu'il reconnaît | S5, S46, S49 |
| Recadrage 'X is not the problem, Y is' | même phrase, deux noms changés | #21, S70, S52 |
| Tableau us vs them / cartes de comparaison / listes ✓✗ | rival = fat burners / gélules d'organes d'élevage ; lignes = résultats et douleurs, jamais des features | #1, #3, S54, S65, S37 |
| Cartoon 'I use X / I use Y' | X = le rival qu'il connaît | S42 |
| Meme (wojak/chad, Barbie/Ken, chat, Muppet, 'said no wife ever', starter pack) | garder la mécanique du meme ; chaque ligne = une scène de SA vie avec le problème | #9, S47, #64, S81, S34, S61 |
| Clay / poupée / Pixar / illustration peinte | même style de rendu, notre avatar ; jamais photoréaliste | S49, S52, S76, S83, S11, S15 |
| Jeu visuel sur une forme | trouver un objet de la même forme que le problème (lune, poire) | S23, S50 |
| Image choc (vers, tas dégoûtant) | aussi choquant pour notre problème : le ventre qui fond comme de la cire | S7, S27 |
| Rituel produit (poudre dans le café, scoop) | le produit à côté de la boisson qu'il a déjà, versée | S18 |
| Ingrédient / 'it's all in here' / produit puzzle | les ingrédients en silhouettes reconnaissables, un rôle simple chacun | S3, #32 |
| Produit enfoui dans ses ingrédients / panneau fait du produit | ingrédients frais et appétissants avec étiquettes | S67, #35, #39 |
| Main qui tient le produit, lumière moody, une stat | le produit dans une main d'homme ; '93% saw their beer belly shrink*' + footnote | S24, S63 |
| Cartes d'offre (special deal, last call, goodbye lowest price, bundle chooser) | prix réel / barré / BOGO / garantie ; pas de cadeau inventé ; jamais Autoship | S13, S36, S44, S74, #46, #49, #51 |
| Challenge / garantie ('90-day challenge', 'XL to M or money back') | leur structure, notre garantie | S41, S68 |
| Post texte seul / manifeste / écrit à la main | mêmes mots, seul l'excuse ou le nom change ; rendu par script ou écriture gardée | S4, S9 |
| UGC (captions TikTok, selfies Day 0/Day 90, unboxing) | sa voix, le problème + la réaction de sa femme ; preuve sociale | S20, S21, S72 |
| Teaser advertorial ('Why men … can't …', 'Read the solution →') | 'Why men with a beer belly after 40 can't keep up with their kids' | S32, S33 |

| Scène sexuelle (couple, draps, comptoir, son dos) | homme plus âgé ; son désir à elle lié au ventre perdu ; Seedream + composite si refus | S11, S12, S30, S55, S58, #65, #79 |

## 3. Angles

- **A1 Beer belly = estrogen** — l'angle par défaut, toujours en premier ; tout template qui porte un autre angle est fusionné avec le ventre
- **A2 Man boobs / puffy chest** — deuxième porte d'entrée, le plus fort scroll-stopper ; un template man boobs ne met en avant que ça
- **Drive / sexuel** — seulement sur les templates sexuels, lié au ventre quand c'est possible
- **A3 Wild vs farmed** — la source : jamais domestiqué vs élevage ; foils génériques seulement
- **A4 'I tested 3' / product system** — listicle comparatif ; les 4 organes, 4 rôles
- **A5 Anti-waste** — 'supplements failed you', '12 pills every morning' ; à utiliser avec parcimonie ('too many')
